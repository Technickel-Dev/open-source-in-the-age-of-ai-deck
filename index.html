Hacktoberfest 2026 · Technickel
Hacktoberfest is a month-long celebration of open source every October. Run by MLH and DEV this year, with DigitalOcean (who started it in 2014) as presenting partner.

The story so far

From four PRs to 500+ events

  1. 2014

    A challenge is born

    DigitalOcean launches Hacktoberfest: open four pull requests in October, earn a t-shirt.

  2. 2015–25

    A generation joins open source

    Thousands make their first contribution. Then maintainers face a flood of low-effort PRs and burnout.

  3. 2026

    A new chapter

    MLH and DEV take over stewardship. Local Fests and online events, all about building with open source AI.

Hacktoberfest 2026 · Technickel
Source: hacktoberfest.com/mission. The big shift: AI tools made low-effort PRs trivial to generate, and maintainers were drowning.

What changed in 2026

Open 4 PRs → get a t-shirt

Learn. Build. Show up.

Pull requests no longer count toward rewards. Open source was never defined by a PR counter.

Pull and merge requests no longer count toward Hacktoberfest rewards. They're listening to maintainer feedback. You're still encouraged to contribute to open source, it's just not the scoreboard anymore.

Hacktoberfest 2026 · Technickel
Walk the six steps. Each click advances one step. The example is my own low-poly repo README PR.

Contributing in the age of AI

Don't be the reason PRs stopped counting

  1. 01

    Read the rules

    CONTRIBUTING.md, and the project's AI policy if it has one.

  2. 02

    Talk first

    Comment on the issue before you open a PR.

  3. 03

    Own every line

    If AI wrote it, you reviewed it, tested it and can explain it.

  4. 04

    Quality over quantity

    One thoughtful PR beats ten drive-bys. Disclose AI help when asked.
